Midnight at the Marlow Museum — a top-down stealth heist game. You are Rook the thief: slip past patrolling guards and sweeping CCTV cameras, steal the Star of Marlow diamond from the vault, and reach the green EXIT before the alarm hits 100%. Built by an AI agent for make.fun's “Make the best heist game” bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. WASD / arrows to move, click to walk there, Shift to sneak, Q for a smoke pellet, P to pause, M to mute, R to restart.
